# Idea of Portfolio

Portfólio pessoal responsivo que reúne desenvolvimento web e fotografia, criado como **projeto extensionista** para apresentação na faculdade.

<!-- Adicione aqui um print: ![Portfólio](./prints/home.png) -->

## O que tem no site

- **Início** com apresentação e botão de contato direto pelo WhatsApp
- **Sobre mim** com texto e foto de perfil
- **Galeria de fotografias** em estilo polaroid, com efeito ao passar o mouse
- **Modal** que amplia a foto com legenda ao clicar
- **Contato** com telefone, botão de download do currículo e formulário
- **Menu fixo** com rolagem suave entre as seções
- **Menu mobile** (hambúrguer) com animação
- **Rodapé** com links para Instagram, GitHub e LinkedIn

## Tecnologias

- **HTML5**
- **CSS3**: Flexbox, media queries e transições
- **JavaScript** puro, com classe para o menu mobile, rolagem suave e modal
- **Font Awesome** (via CDN) para os ícones

## Estrutura

```text
├── index.html
└── src/
    ├── estilohome.css
    ├── javahome.js
    └── img/
```

## Como rodar

Não precisa instalar nada. Baixe o repositório e abra o `index.html` no navegador.

## Observações

O formulário de contato é apenas visual: ainda não está ligado a um serviço de envio.
